# pages/admin/

Admin dashboard pages (calmer UI, function over animation):
- Dashboard/overview (sales stats, active orders)
- User management (customers, staff, riders)
- Menu management (add/edit items, images, prices in Tk, weather-dish mapping)
- Inventory management
- Order management (view/cancel/refund, generate bill)
- Table management (floor plan editor, live status)
- Staff management (optional)
- Payment management
- Customer management (complaints, reviews, promotions, loyalty)
- Reports & Analytics (Grok AI powered)
- System settings
