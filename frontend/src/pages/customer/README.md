# pages/customer/

Customer-facing pages (fine-dining, TerraElix-style animated UI):
- Landing/Home page (hero section)
- Menu page (grid/column layout, categorized, with images, ingredients, weather recommendations)
- Food detail page (ingredients, reviews/ratings)
- Table reservation page (live floor plan, green/red status)
- Order/checkout page (Dine-in / Takeaway / Online, Tk pricing, payment method selection)
- Order tracking page (status + ETA + "message admin if late")
- Order history page
- Reviews page (leave a review after completed order)
