# src/styles/

Global styling:
- index.css / globals.css -> Tailwind imports + custom CSS keyframes
  (fadeUp, fadeIn, slideInLeft, slideInRight, scaleIn, wordReveal — from the
  TerraElix-style animation reference)
- tailwind.config.js -> Tailwind theme customization (fine-dining color palette,
  fonts: e.g. Playfair Display / Cormorant for headings + Inter for body)
